# Futty ⚽

A simple browser football game: you (blue) against a CPU opponent (red) in a 90-second match.

## Play

Open `index.html` in any modern browser. Nothing to install and no build step.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | Arrow keys / WASD | Drag on the pitch |
| Kick | Space (hold for more power) | KICK button |
| Pause | P | — |
| Start / restart | Enter | Kick Off button |

Score in the **right** goal. Run into the ball to dribble it; kick it in the direction you are facing.
You can pick Easy, Normal or Hard on the start screen.
